# 4.2 圖台

## 4.2.1 底圖

| 項目 | 規格 |
| --- | --- |
| 電子地圖 | 國土測繪中心 WMTS EMAP 服務（預設） |
| 正射影像圖 | 國土測繪中心 WMTS PHOTO2 服務 |
| 地形圖 | 臺北市歷史圖資WMTS服務 |
| 最小縮放層級 | 12（鄉鎮層級） |
| 最大縮放層級 | 20（地塊層級） |
| 預設範圍 | 顯示所有土地資料，若超過縮放層級上限則維持上限並定位所有資料中間點 |

服務位址：

- 電子地圖：`https://wmts.nlsc.gov.tw/wmts/EMAP/default/GoogleMapsCompatible/{z}/{y}/{x}`
- 正射影像圖：`https://wmts.nlsc.gov.tw/wmts/PHOTO2/default/GoogleMapsCompatible/{z}/{y}/{x}`
- 地形圖： `https://www.historygis.udd.gov.taipei/WMTS/`

## 4.2.2 Tooltip 顯示時機

地圖層級縮放至 17 以上時，滑鼠移過每一塊地籍時顯示，欄位詳 §2.6

# 4.3 土地資料面板

面板分2頁，檢視時預設顯示「土地資料」頁，編輯時預設顯示「實地勘查土地現況」頁。欄位列表見 [§2.3](./2%20資料規格.md#23-面板頂部固定區塊欄位) ~ [§2.4](./2%20資料規格.md#24-土地勘查作業欄位)

| 項目 | 說明 | 顯示方式 |
| --- | --- | --- |
| 土地資料 |  |  |
| 土地標示 | 唯讀 | 資料區塊 |
| 套匯圖資 | 唯讀 | 資料區塊 |
| 實地勘查土地現況 |  |  |
| 實地勘查土地現況 | 勘查時間、勘查人員、提交批次唯讀；土地坐落以下 6 欄可編輯 | 資料區塊 |
| 原始資料比對 | 狀態為「已修正」時，內業人員／管理者可展開查看退回前之原始版本，逐欄位與目前資料並列比對（依賴 [§2.4.2.2](./2%20資料規格.md#2422-退回快照) 退回快照） | 按鈕／區塊 |
| 以下共通元件不分頁 |  |  |
| 頂部固定區塊 | 捲動時持續顯示 | 面板中固定區塊 |
| 街景 | 點擊另開新視窗顯示該土地 街景 | 按鈕 |
| 期別切換 | 切換至歷史期別，切換後實地勘查土地現況區塊全部唯讀 | 下拉選單 |
| 編輯 | 點擊後開放編輯實地勘查土地現況區塊之可輸入欄位 | 按鈕 |
| 查核通過 | 資料狀態為「外業調查完成」、「已修正」時顯示 | 按鈕 |
| 退回 | 資料狀態為「外業調查完成」、「已修正」時顯示 | 按鈕 |

## 4.3.1 退回意見面板

| 元件 | 元件類型 | 說明 |
| --- | --- | --- |
| 退回意見 | 多行文字 | 必填 |
| 確認退回 | 按鈕 | 狀態變更為「退回」 |
| 取消 | 按鈕 | 關閉面板，不變更狀態 |

退回意見顯示於 APP 土地詳情頂部醒目區塊，直至該土地重新送出並選擇已修正完成。

# 4.4 APP 填報畫面

填報表單僅呈現 6 個可輸入欄位。勘查時間、勘查人員、提交批次由系統帶入，以唯讀方式顯示於表單頂部，不提供編輯入口。

| 元件 | 元件類型 | 說明 |
| --- | --- | --- |
| 土地資訊區塊 | 區塊 | 顯示頂部固定區塊與土地標示、套匯圖資欄位，唯讀 |
| 系統帶入資訊列 | 區塊 | 顯示勘查時間、勘查人員、提交批次，唯讀 |
| 退回意見區塊 | 區塊 | 狀態為「退回」時顯示，醒目色 |
| 填報表單 | 表單 | 可輸入欄位詳 [§2.4.2.1](./2%20資料規格.md#2421-實地勘查土地現況區塊可編輯) |
| 拍照 | 按鈕 | 開啟相機，不提供相簿上傳 |
| 照片縮圖列 | 區塊 | 已拍攝照片縮圖，可刪除重拍 |
| 送出 | 按鈕 | 通過 [§3.2](./3%20系統行為規則.md#32-欄位條件必填規則) 驗證後送出，同時寫入勘查時間、勘查人員 |
