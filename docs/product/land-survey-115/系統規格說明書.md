# 系統規格說明書

> 新工處土地占用調查圖台系統
> 

# 一、文件目的與適用範圍

本文件為新工處土地占用調查圖台系統之系統規格說明書，供開發、測試與維運人員參照。系統分為 WEB 與 APP 兩個端點，供公司內部與外包廠商使用。

本案調查土地為臺北市之市有土地。

本次調查工作範圍為**實地勘查土地現況**。清冊之協調訪查作業不屬本次範圍。
