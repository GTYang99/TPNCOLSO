# 2. 資料規格

> 本章定義各欄位的顯示標籤、順序、型別與顯示規則。
> 

> 欄位之 API 回傳名稱、回傳值定義與資料結構詳見後端 API 規格書。
> 

# 2.1 共通顯示規則

| 類型 | 規則 | 範例 |
| --- | --- | --- |
| 空值 | 統一顯示「-」。 | 包括空白、null、空字串 |
| 日期 | 介面統一顯示民國年，年不補0、月日補0。 | 114/03/05、89/01/18 |
| 數值 | 千分位分隔。小數位數依欄位定義，不足補0。 | 1,234.50 |
| 複選欄位 | 多值以半形逗號加空格「, 」串接 | 雨遮, 斜坡道 |

# 2.2 註冊

| 順序 | 顯示標籤 | 欄位名稱 | 型別 | 元件類型 | 可空 | 顯示規則／選項 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 帳號 | user_account | varchar(30) | 文字輸入 | 否 | 僅限英、數，最多 30 字元 |
| 2 | 密碼 | user_password | varchar(30) | 文字輸入 | 否 | 英、數、特殊符號，至少8碼 |
| 3 | 廠商名稱 | user_campany | Nvarchar(30) | 下拉選單 | 否 | 後端預先登錄廠商名單，選項依照名單 |

# 2.2 土地識別碼

系統以 key_no 作為土地之內部唯一識別碼，供資料庫主鍵與 API 查詢使用。地號全銜字串（land_no）為對外顯示與匯出用之衍生欄位，兩者並存，用途不同。

## 2.2.1 key_no（系統主鍵）

| 項目 | 規格 |
| --- | --- |
| 欄位名稱 | key_no |
| 組成 | 縣市代碼 1 碼+行政區編碼2碼 + 地段代碼 4 碼 + 地號 8 碼 |
| 總長度 | 15 碼，定長 |
| 型別 | Char(15) |
| 唯一性 | 是（Unique） |

## 2.2.2 land_no（顯示與匯出用）

| 項目 | 規格 |
| --- | --- |
| 欄位名稱 | land_no |
| 內容 | 地號全銜字串，含中文與數字 |
| 型別 | Nvarchar(30) |
| 產生方式 | 隨清冊匯入直接取得 |
| 範例 | 臺北市松山區西松段一小段0093-0000地號 |

來源清冊 1,461 筆地號經檢核完全唯一，字串長度 20~23 字元。**land_no 僅為顯示與匯出用途，系統內部查詢、路徑參數與資料庫主鍵一律使用 key_no。**

## 2.4.2.2 退回快照

土地狀態變更為「退回」時，系統將當下之欄位 4~10（土地坐落、現場勘查土地情形、占用型態、占用戶數、占用門牌號、備註、現況照片）完整複製一份，作為該次退回之原始版本，供內業人員比對用。

| 項目 | 規則 |
| --- | --- |
| 儲存時機 | 狀態變更為「退回」的當下 |
| 儲存範圍 | 欄位 4~10（不含系統帶入之勘查時間、勘查人員、提交批次） |
| 覆蓋規則 | 每次退回覆蓋前一份快照，只保留最新一次退回前的版本 |
| 清除時機 | 狀態變更為「已查核」後，快照可清除；未查核前持續保留供比對 |

## 2.4.3 系統帶入欄位補充規則

| 事項 | 說明 |
| --- | --- |
| 退回後重新送出時，勘查時間是否更新 | 更新為重新送出當日。需存原始勘查日期及原始值 |
| 內業修改權限 | 內業人員於 WEB 修正資料時，勘查時間與勘查人員維持原值 |
